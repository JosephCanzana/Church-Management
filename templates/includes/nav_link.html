{% comment %} nav_link.html: one navigation link, in one of three layouts. Variables: item (an entry from nav.sections, nav.bottom_items or nav.more_items) and layout: rail = icon only with a tooltip (desktop rail), row = icon and label side by side (panel, More sheet), tab = icon above label (mobile bottom bar). A disabled item (route not built yet) has no href and is dimmed. Colours are tokens only; state classes are chosen here, so no CSS needs adding to input.css. Usage: {% include 'includes/nav_link.html' with item=item layout='rail' %} {% endcomment %} {% if layout == 'rail' %} {% include 'includes/icon.html' with name=item.icon class='size-5' %} {{ item.label }} {% elif layout == 'tab' %} {% include 'includes/icon.html' with name=item.icon class='size-5 shrink-0' %} {{ item.label }} {% else %} {% include 'includes/icon.html' with name=item.icon class='size-5 shrink-0' %} {{ item.label }} {% endif %}
