{% comment %} topbar.html: right-hand side of the app header, on the frame color. A notification bell that opens a frosted-glass dropdown with the latest five notifications (a "View all" link goes to the full page), then a quiet avatar button. The avatar opens a small account menu that holds the name, the role, the profile link and Log out (a POST form with the same confirm dialog as the sidebar), so the name no longer competes with the page title. The bell shows a dot when unread_count is above zero. Below sm the notification dropdown is fixed under the header and spans the screen so it never runs off the edge; from sm up it hangs under the bell. The account menu hangs under the avatar at every size. The header, the menu button and the page title live in base_app.html, because a block inside an included file never overrides anything. Variables: user (from the auth context processor), unread_count and recent_notifications (from notifications.context_processors.bell). Usage: {% include 'includes/topbar.html' %} {% endcomment %}
