{% comment %} topbar.html: right-hand side of the app header, on the frame color. A notification bell that opens a frosted-glass dropdown with the latest five notifications (a "View all" link goes to the full page), then the signed-in user as a glass chip linking to their profile: the profile photo (or a solid initials badge when there is none), plus name and role from sm up. The bell shows a dot when unread_count is above zero. Below sm the dropdown is fixed under the header and spans the screen so it never runs off the edge; from sm up it hangs under the bell. The header, the menu button and the page title live in base_app.html, because a block inside an included file never overrides anything. The light/dark toggle and log out are in sidebar_utilities.html. Variables: user (from the auth context processor), unread_count and recent_notifications (from notifications.context_processors.bell).
