{% comment %} dashboards/report_print.html Standalone A4 church report for the browser's print dialog ("Save as PDF" is a print destination), opened from the dashboard's "Print report" button. It is NOT a print of the dashboard: different layout on purpose, TABLES first, then two grayscale charts, then three signature lines. It does NOT extend base_app.html: black text on white whatever the person's light or dark mode, inline CSS, no external fonts, no Tailwind, no includes/logo.html; the logo is a plain of black-logo.svg. Same conventions as attendance/print.html and tithes/print.html (toolbar and grey desk are screen-only, no page numbers). Context (dashboards.views.report_print): report (get_report_context): filter, period, include_giving, query, prepared_for, summary_lines, dashboard_url, attendance_stats, network_table, attendance_gap, people_stats, extension_table, events, giving_stats, prayer (counts only), charts. Order: header (church, extension or "All extensions", period, as-of, prepared for) | 3-line summary | attendance per gathering | age network x gender | people by role and status | extensions (admin and super-admin, All only) | events | giving (only when included) | prayer counts | attendance line | age x gender columns | signatures | printed-at line. Privacy: counts, dates and amounts only. Never a person's name, birth date, phone number or address, never prayer request text, and giving only when the report says so. Printed times are Manila time. Printing notes: every block avoids a page break inside it, except the long tables (attendance, extensions, events, giving), which may flow across pages: their header row repeats and their rows never split.
